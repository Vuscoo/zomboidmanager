# Nexus Mods page copy (English) — Zomboid Manager v1.1.0

## Suggested title
**Zomboid Manager — Local Dedicated Server Control Panel**

## Short summary
**Zomboid Manager** is a simple Windows app for running your **Project Zomboid dedicated server** locally. Start, configure, restart, back up, broadcast, and admin your world from one clean panel — no remote shell, no public RCON exposure.

---

## Full description (paste into Nexus)

```
🧟 Zomboid Manager
Local dedicated server control for Project Zomboid (Build 42 friendly)

Tired of juggling console windows, .ini files, and random notepad tabs?
Zomboid Manager puts your dedicated server in one dark, focused control panel —
built for local hosts who want power without the pain.

✨ WHAT YOU GET

🖥️ Server control
• Start / Stop / Restart from the app
• Live status, address, players online, last restart
• Compact server console with timestamps
• Hardware panel: live CPU, RAM & disk usage + configured ports

⏰ Restarts that respect your players
• Schedule automatic hourly restarts
• Custom shutdown message
• Optional 10-minute & 5-minute chat warnings (1-minute warning still included)

🛠️ Tools that save time
• 📢 Server Broadcaster — up to 5 one-time or recurring chat messages via RCON
• 💾 Backup Manager — dated backups + weekly/one-time auto schedules
• 📜 Log Viewer — important logs from server\logs and Zomboid\Logs
• 📘 Admin Command Reference — searchable Build 42 commands (EN/DE keywords)
• 🧩 Mod List — Workshop & Mod IDs with Steam links
• 📣 Discord webhooks — start/stop/restart + timed custom messages

👥 Player management (RCON)
• Search players, per-player action menu
• Kick / ban / unban (name + SteamID)
• Set access level, godmode, invisible, teleport, give item / XP
• Whitelist helpers + server messages

⚙️ Config without the headache
• Edit server.ini with categories + live search
• Clean “Mods & Workshop” (Workshop IDs + Mod IDs only)
• Dedicated SandboxVars.lua categories (gameplay rules where they belong)
• Smarter StartServer*.bat auto-detect + Browse in Settings

🌍 Multi-language UI
• English & German fully covered; more languages for core UI

🛡️ SAFE BY DESIGN
• Local Windows app only — not a public web panel
• No remote shell
• Keep RCON on localhost / your LAN — never expose it to the open internet

📦 REQUIREMENTS
• Windows 10/11 (x64)
• Microsoft Edge WebView2 Runtime (usually already installed)
• Your Project Zomboid dedicated server folder + start .bat
• Optional: RCON enabled in server.ini for player / broadcast / status tools

🚀 HOW TO USE
1. Download ZomboidManager.exe (single file)
2. Run it
3. Settings → set Server folder, Zomboid data folder, start .bat, RCON
4. Manage everything from Server / Restarts / Config / RCON / Tools

📌 NOTES
• Settings & UI cache live under %LocalAppData%\ZomboidManager\
• Backups are created next to the app (Backups\)
• One EXE is enough — no installer required
```
