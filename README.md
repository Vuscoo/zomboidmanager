Zomboid Manager
Local dedicated server control for Project Zomboid

Zomboid Manager is a Windows desktop app that helps you run and manage your Project Zomboid dedicated server in one place. Built for local server hosts who want a clear, safe control panel — without remote shells or exposing RCON to the internet.

WHAT IT DOES
• Start / Stop / Restart your server from the app
• See server status, address, players online, and last restart
• Open a live server console when launching from the manager
• Schedule automatic restarts by the hour
• Edit server.ini with categories, search, and show/hide all
• Edit SandboxVars.lua in the same Config tab (e.g. MultiHitZombies)
• Use RCON console + quick commands (players, save, message, quit)
• Browse your mod list with Steam Workshop links
• Create dated backups of important configs and multiplayer saves
• Manage players via RCON (kick, ban, unban, access level, whitelist, server message)
• Send Discord webhook events for start/stop/restart + custom timed messages
• Multi-language UI (English/German full, more languages for core UI)

WHO IT'S FOR
Anyone hosting a Project Zomboid dedicated server on Windows who wants easy local control: config, backups, player admin, and notifications without a complicated external panel.

REQUIREMENTS
• Windows 10/11 (x64)
• Microsoft Edge WebView2 Runtime (usually already installed)
• Your Project Zomboid dedicated server files + StartServer64.bat (or similar)
• Optional: RCON enabled in your server.ini for player/status tools

HOW TO USE
1. Extract the zip
2. Run ZomboidManager.exe
3. Set Server folder, Zomboid data folder, start .bat, and RCON in Settings
4. Use Server / Config / Tools as needed
