# Feature roadmap (research 2026)

Strong already: restarts, RCON, INI editor, settings, status.

## Done / in progress
1. **Embedded server console** — Start/Stop/Restart + log in the Server tab (local only, no remote shell)
2. **World backups** — `Backups/` in app root, dated folders, important Server configs + Multiplayer saves
3. **SandboxVars.lua editor** — Tools → Sandbox Editor (MultiHitZombies etc.)
4. **Multi-language UI** — full string catalog (de/en complete; other langs for common UI)

## Next ideas (short)
5. **Player admin** — kick/ban/whitelist/admin via RCON
6. **Mod manager** — add Workshop IDs, reorder, Steam metadata beyond the current Mod List
7. **Live map** — needs Lua/map bridge; open external map URL for now
8. **Discord notifications** — restart / join events (webhook, not public RCON)
9. **SteamCMD update** — one-click dedicated server update
10. **Backup restore** — restore a dated `Backups/` folder into Zomboid data
